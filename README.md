# Dipendu Dey – Portfolio

Personal portfolio built with React (Create React App) and Framer Motion.

- Content lives in `src/data.js`: edit it to update roles, skills, stats and links.
- Sections live in `src/components/Sections.jsx`; styles in `src/index.css`.

```bash
npm install
npm start      # dev server on http://localhost:3000
npm run build  # production build
```
